# Contribuciones a PurpleMD

Gracias por tu interés en PurpleMD.

## Modelo del proyecto

PurpleMD es software de **código fuente disponible** (source-available) bajo
la licencia [AGPL-3.0](LICENSE). El código está público para lectura,
auditoría y uso personal.

## Política de Pull Requests

**No se aceptan Pull Requests de código externo** en este momento.

Esta decisión busca preservar:

- La **visión de diseño** y coherencia de producto.
- La **integridad arquitectónica** del código base.
- La **titularidad limpia** del código de cara a futuros modelos de
  monetización y soporte Enterprise.

No es una reflejo de la calidad de las contribuciones propuestas —la
apreciamos— sino una decisión estratégica del proyecto.

## Qué sí es bienvenido

Las siguientes contribuciones están abiertas y son muy valoradas:

- **Issues de bugs**: reportes detallados con pasos de reproducción.
- **Sugerencias de funcionalidades**: ideas conceptuales y casos de uso.
- **Mejoras de documentación**: correcciones o ampliaciones en README,
  wiki o docs/.
- **Reportes de seguridad**: ver [SECURITY.md](https://github.com/ltrecanao/purplemd/security).
